# 📒 Address Book Management System in C

## 📌 About the Project

The **Address Book Management System** is my first major project developed using the C programming language. It is a menu-driven application designed to manage contact information efficiently.

This application provides essential contact management operations through a simple and user-friendly interface, along with file handling to maintain contact details.

## ✨ Features

- **Create Contact** – Add new contacts with personal details.
- **Search Contact** – Search for contacts using name, phone number, or email.
- **Edit Contact** – Modify existing contact information.
- **Delete Contact** – Remove contacts when they are no longer needed.
- **Display Contacts** – View all saved contacts in alphabetical order.
- **Save & Exit** – Save contact information and safely exit the application.

## 🛠️ Technologies Used

- **Programming Language:** C
- **Compiler:** GCC
- **IDE:** Visual Studio Code
- **Storage:** File Handling (CSV)

## 🧠 Concepts Implemented

- Structures and Pointers
- Functions and Modular Programming
- String Handling
- File Handling
- Searching and Sorting
- Input Validation

## ⚙️ How to Compile and Run

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd Address-Book-Management-System
   ```

3. Compile the source files:

   ```bash
   gcc *.c -o addressbook
   ```

4. Run the application:

   ```bash
   ./addressbook
   ```
